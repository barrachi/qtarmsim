QtARMSim
========

QtARMSim is an easy to use graphical ARM simulator. It provides an easy
to use multiplatform ARM emulation environment that has been designed
for Computer Architecture introductory courses.

The ARMSim ARM simulator, Copyright (c) 2014-2020 by Germán Fabregat, is
bundled with QtARMSim. It can be found on the ``armsim_ruby/``
subdirectory. To avoid the ``Python`` and ``Ruby`` dependencies, a transpiled
to Python version of this simulator has been generated. It can be found
on the ``armsim/`` subdirectory.
