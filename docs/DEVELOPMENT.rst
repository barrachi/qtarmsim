QtARMSim development process
============================

To enter de development mode::

    $ nix develop

To run the current development version::

    $ uv run qtarmsim

Commit and push all the changes, after that, to test that everything is fine::

    $ nix run --refresh github:barrachi/qtarmsim

Once everything is fine, bump version::

    $ git tag {VERSION}[rcN]
    $ git push --tags

To build and publish the current tagged version::

    $ uv build
    $ uv publish

To test the PyPI version::

    $ uvx qtarmsim=={VERSION}[rcN]

To download the stand-alone executables generated by GitHub:

- Go to GitHub → Actions tab → click the workflow run → scroll down to Artifacts.
- Update the QtARMSim Home page.

Just in case, to generate an AppImage::

  nix bundle --refresh --bundler github:NixOS/bundlers#toAppImage github:barrachi/qtarmsim
